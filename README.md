# مكتبتي الرقمية الخاصة

تطبيق ويب عربي (RTL) لإدارة المواقع والروابط والملفات والحسابات وأدوات الذكاء الاصطناعي والمشاريع.
التقنية: React + TypeScript + Vite + Tailwind، وقاعدة البيانات والمصادقة والتخزين عبر Supabase.

## حالة المشروع (المرحلة 1)

منجز:
- هيكل المشروع، RTL، الوضع الداكن/الفاتح، ألوان الأسود والرمادي والذهبي.
- مخطط قاعدة البيانات الكامل مع سياسات RLS وحاوية تخزين خاصة (`supabase/schema.sql`).
- تسجيل الدخول، تسجيل الخروج، استعادة كلمة المرور، حماية الصفحات.
- القائمة الجانبية (سطح المكتب والجوال) ولوحة التحكم بإحصائيات حقيقية وتنبيهات الانتهاء.

لم يُبنَ بعد (المراحل التالية، قسمًا قسمًا مع اختبار كل قسم):
المواقع، الروابط، الملفات، الخزنة، أدوات الذكاء الاصطناعي، المشاريع والمهام، الملاحظات، المفضلة، التنبيهات، البحث الشامل، الأدوات الإضافية (QR، Excel، النسخ الاحتياطي…).

> تنبيه: كُتب هذا الكود في بيئة لا تستطيع تثبيت حزم npm، لذلك **لم يُشغَّل `npm run build` ولم يُختبر**. عند أول تشغيل على جهازك أخبرني بأي خطأ يظهر لأصلحه.

## التشغيل

1. ثبّت Node.js 18 أو أحدث.
2. أنشئ مشروعًا مجانيًا على https://supabase.com.
3. من **SQL Editor** شغّل محتوى `supabase/schema.sql` كاملًا.
4. من **Authentication > Providers > Email**: أوقف **Allow new users to sign up** (لمنع التسجيل العام).
5. من **Authentication > Users > Add user** أنشئ حساب المدير (بريد + كلمة مرور).
6. من **Authentication > URL Configuration** أضف عنوان موقعك (مثل `http://localhost:5173`) إلى Redirect URLs ليعمل رابط استعادة الحساب.
7. انسخ `.env.example` إلى `.env.local` وضع `Project URL` و`anon public key` (من Project Settings > API).
8. نفّذ:

```bash
npm install
npm run dev
```

افتح http://localhost:5173 وسجّل الدخول بحساب المدير.

## النشر

```bash
npm run build
```

ارفع مجلد `dist` على Netlify أو Vercel أو Cloudflare Pages (مجانًا)، وأضف متغيري البيئة `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` في إعدادات الاستضافة، وأضف رابط الموقع في Redirect URLs في Supabase. على Netlify/Cloudflare أضف قاعدة إعادة توجيه `/* → /index.html` لأن التطبيق Single Page.

## الأمان

- يُستخدم مفتاح `anon` العام فقط في الواجهة. لا تضع مفتاح `service_role` في أي ملف من المشروع.
- كل جدول مفعّل عليه RLS بحيث لا يصل أي مستخدم إلا إلى صفوفه (`user_id = auth.uid()`)، والملفات في حاوية خاصة بمجلد لكل مستخدم.
- كلمات مرور الخزنة ستُشفَّر داخل المتصفح (AES-GCM بمفتاح مشتق من كلمة مرور رئيسية) قبل الإرسال، فلا تُخزَّن كنص مكشوف. (يُنفَّذ في مرحلة الخزنة؛ الجداول جاهزة: `credentials` و`vault_meta`.) ملاحظة: إن نسيت الكلمة الرئيسية للخزنة فلا يمكن استرجاع كلمات المرور.

## هيكل المشروع

```
supabase/schema.sql      مخطط القاعدة + RLS + Storage
src/lib/                 اتصال Supabase، سجل العمليات، قائمة الأقسام
src/context/             المصادقة والثيم
src/components/Layout    القائمة الجانبية والشريط العلوي
src/pages/               الدخول، الاستعادة، لوحة التحكم، الأقسام
```
